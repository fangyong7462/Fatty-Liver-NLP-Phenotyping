# Rule priority

The public candidate preserves the true frozen source order exactly:

1. Severe
2. Moderate
3. Trend / uncertainty / borderline
4. Mild and the unqualified Chinese generic fatty-liver expression
5. Explicit negative / absence
6. Default Normal

Because negation is evaluated after the Mild pattern, some Chinese negative strings that contain 脂肪肝 may be returned as Mild. This is inherited source behavior, not a new correction. The exposure audit found zero such constructions in the analyzed and validation corpora. A future deployment implementation should consider negation-first logic and an Unclassified/abstention route; this package remains the exact research implementation.
